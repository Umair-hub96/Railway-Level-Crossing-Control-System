# Railway Level-Crossing Control System

## Project Overview

The Automated Railway Level-Crossing Control System (ARLCCS) automatically controls road traffic when a train approaches, passes through, and clears a railway crossing.

The system uses train-detection sensors, road barriers, warning lights, audible alarms, traffic signals, a safety-monitoring unit, and a control-center interface.

## Project Objectives

- Identify important system constraints.
- Convert constraints into formal logical expressions.
- Identify realistic scenarios where constraints can be violated.
- Explain how the system detects constraint violations.

## Tasks

### Task 1 — Identify Constraints
Identified 10 important constraints that the railway crossing system must satisfy.

### Task 2 — Formalize Constraints
Converted the identified constraints into formal logical expressions using AND, NOT, and implication.

### Task 3 — Identify Constraint Violations
Created realistic violation scenarios for the formalized constraints and explained how each violation can be detected.
